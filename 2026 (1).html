이 게임을 인터넷에 무료로 올리는 2가지 방법

방법 1. 드래그 한 번으로 출시 (가장 쉬움) 추천 • 10초 소요
  1. 우측 상단 파일창의 index.html 코드를 내 컴퓨터에 저장합니다.
  2. Netlify Drop (app.netlify.com/drop) 사이트에 접속합니다.
  3. 저장한 index.html 파일만 마우스로 끌어다 놓으면 정식 웹사이트 주소(https://...netlify.app)가 발급됩니다!
방법 2. GitHub Pages 이용하기 영구 무료 호스팅

GitHub 저장소(Repository)를 만들고 index.html을 업로드한 뒤, Settings ➔ Pages에서 해당 브랜치를 지정하면 영구적인 내 전용 웹사이트가 생성됩니다.

발급받은 웹사이트 주소를 [QR 공유] 메뉴에 넣으면 스마트폰으로 바로 들어올 수 있습니다!
